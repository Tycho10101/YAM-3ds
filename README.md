
# YAM-3ds
> [!WARNING]
> This project is still in a highly early stage, and contains no gameplay. Please return at a later date.

> [!NOTE]
> **Disclaimer:** This project is not affiliated with Mojang or Nintendo.

YAM 3DS stands for Yet Another Minecraft for the 3DS; A 2D Minecraft clone for the 3DS made in Lua using LÖVE Potion.
